## Key decisions
- **PIM (nex-shopify master), nie „ľahká cesta"** (Director) — profesionálna architektúra, jeden zapisovateľ + dve zrkadlá (rieši dual-write).
- **Sklad zostáva zdroj Genesis** (výnimka z PIM) — fyzický počet žije v sklade.
- **Genesis API = 3 doménové Delphi servery** (Director) — Delphi 6 no-async → doménová izolácia + nezávislý deploy.
- **Tibor mapuje interné metadáta → dohodnuté `parameters`; nex-shopify je relay** (Director) — my definujeme cieľovú sadu = Shopify metafieldy (namespace `pneu`).
- **Mapovací kľúč: PLU = SKU = id starého eshopu** naprieč Genesis/Shopify/migrácia.
